# Overview

Automates the maintenance and consistency of AsciiDoc documentation in the Particle Pinball project.
Ensures documentation stays synchronized with code changes, follows consistent formatting, and maintains high quality standards.

# Responsibilities

## 1. Documentation Synchronization
- **Code-Doc Alignment**: Ensure documentation reflects current code implementation
- **API Reference Updates**: Update docstrings and API documentation when code changes
- **Cross-Reference Validation**: Verify all internal links and references are valid
- **Version Consistency**: Keep version numbers and dates synchronized across files

## 2. Content Quality Assurance
- **Style Guide Enforcement**: Ensure consistent AsciiDoc formatting and style
- **Grammar and Spelling**: Check for grammatical errors and typos
- **Structure Validation**: Verify proper document hierarchy and organization
- **Code Block Validation**: Ensure code examples are syntactically correct

## 3. Automated Updates
- **Table of Contents**: Regenerate TOCs when structure changes
- **Index Updates**: Update navigation and index files
- **Attribute Management**: Maintain consistent document attributes
- **Link Validation**: Check and fix broken internal and external links

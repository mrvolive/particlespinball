= Bumper Demo Documentation

The Bumper Demo simulates a complete pinball game environment, demonstrating collision detection, vector reflection, and energy conservation through interactions with circular obstacles (pegs) and boundary walls. This documentation covers the physics principles, implementation details, and educational value of the demo.

== Overview

The Bumper Demo creates a classic pinball-style environment where a ball bounces off static circular obstacles (pegs) within boundary walls. This simulation demonstrates fundamental physics concepts including:

[.demo-highlights]
* **icon:arrow-circle-down[role=blue] Collision Detection** - Precise detection between ball and obstacles
* **icon:sync[role=green] Vector Reflection** - Realistic bounce behavior using vector mathematics
* **icon:battery-half[role=orange] Energy Conservation** - Understanding coefficient of restitution
* **icon:mountain[role=purple] Inclined Plane Physics** - Gravity modification based on board tilt
* **icon:graduation-cap[role=red] Educational Tool** - Hands-on learning of classical mechanics

== Key Physics Concepts

=== Vector Reflection

The cornerstone of this demo is the vector reflection formula, which calculates how velocity changes after colliding with a surface.

[latexmath]
++++
\vec{R} = \vec{J} - 2(\vec{J} \cdot \vec{N})\vec{N}
++++

Where:
* icon:arrow-right[role=navy] **R** = Reflected velocity vector (new velocity)
* icon:arrow-right[role=navy] **J** = Incident velocity vector (original velocity)
* icon:arrow-right[role=navy] **N** = Normal vector at collision point (perpendicular to surface)
* icon:arrow-right[role=navy] **·** = Dot product operation

**Code Implementation:**
[source, python,linenums]
----
# src/views/demos/bumper_view.py:147-148
reflected = self.ball.velocity - 2 * self.ball.velocity.dot(normal) * normal
self.ball.velocity = reflected * self.ball.bounciness
----

The formula works by:
. Projecting the incident velocity onto the normal: `J · N`
. Subtracting twice the projection from the incident velocity
. Resulting in a velocity vector reflected across the surface normal

=== Coefficient of Restitution

The coefficient of restitution (bounciness) determines how much kinetic energy is retained after collision.

[latexmath]
++++
v_{after} = v_{reflected} \times e
++++

Where *e* is the coefficient of restitution (0 to 1).

* **e = 1**: Perfectly elastic collision (100% energy retained)
* **e = 0**: Perfectly inelastic collision (0% energy retained)
* **e = 0.8**: Realistic bounce (80% energy retained - default value)

**In the Demo:**
[source, python,linenums]
----
# src/objects/ball.py:97-100
self.ball.velocity = reflected * self.ball.bounciness
# With bounciness = 0.8, 20% of energy is lost per collision
----

=== Normal Vector Calculation

For accurate reflection, we need the surface normal vector at the collision point. Different shapes require different normal calculations.

**Circular Obstacles (Pegs):**
The normal points from the obstacle center to the collision point.

[source, python,linenums]
----
# src/objects/bumper.py:60-77
direction = Vector2(ball.rect.center) - Vector2(self.rect.center)
if direction.length() == 0:
    return Vector2(0, 0)  # Degenerate case
return direction.normalize()
----

**Horizontal Walls:**
The normal is always vertical (up or down).

[source, python,linenums]
----
# src/objects/horizontal_wall.py:37-52
dy = ball.rect.centery - self.rect.centery
return Vector2(0, 1) if dy < 0 else Vector2(0, -1)
----

**Vertical Walls:**
The normal is always horizontal (left or right).

[source, python,linenums]
----
# src/objects/vertical_wall.py:37-52
dx = ball.rect.centerx - self.rect.centerx
return Vector2(1, 0) if dx < 0 else Vector2(-1, 0)
----

=== Inclined Plane Physics

When the game board is tilted, effective gravity changes based on the inclination angle.

**Gravitational Force:**
[latexmath]
++++
\vec{F}_{effective} = m \cdot g \cdot (1 - \theta)
++++

Where θ is the inclination (0 to 1).

**Code Implementation:**
[source, python,linenums]
----
# src/views/demos/bumper_view.py:126-127
self.ball.add_force(Vector2(0, GRAVITY * self.ball.mass))
self.ball.add_force(Vector2(0, -GRAVITY * (1 - self.board.inclination) * self.ball.mass))
----

In the Bumper Demo:
* `inclination = 1` (vertical board)
* Effective gravity is minimized, allowing for more predictable bounces

=== Collision Detection Strategy

The demo uses a look-ahead collision detection to prevent tunneling (ball passing through objects).

[source, python,linenums]
----
# src/views/demos/bumper_view.py:130-151
# Calculate new position before moving
new_x = self.ball.x + self.ball.velocity.x
new_y = self.ball.y + self.ball.velocity.y

# Check if the new position would cause a collision
would_collide, colliding_object = self.board.would_ball_collide(
    self.ball, new_x, new_y
)

if would_collide:
    # Handle collision response
    normal = colliding_object.get_normal(self.ball)
    reflected = self.ball.velocity - 2 * self.ball.velocity.dot(normal) * normal
    self.ball.velocity = reflected * self.ball.bounciness
else:
    # No collision, update normally
    self.board.update()
    self.ball.update()
----

This approach ensures:
* No tunneling through obstacles
* Accurate collision response
* Stable physics at high velocities

### Collision Response Example

**Scenario**: Ball traveling at 45° angle collides with a vertical wall

1. **Initial State**:
* Velocity: v = (5, 5) m/s
* Wall normal: N = (-1, 0) (points left)

2. **Calculate Reflection**:
[latexmath]
++++
\vec{R} = (5, 5) - 2[(5, 5) \cdot (-1, 0)](-1, 0)
\vec{R} = (5, 5) - 2(-5)(-1, 0)
\vec{R} = (5, 5) - (10, 0)
\vec{R} = (-5, 5)
++++

3. **Apply Bounciness**:
[latexmath]
++++
v_{new} = (-5, 5) \times 0.8 = (-4, 4)
++++

4. **Result**: Ball bounces horizontally left at 80% of original speed

== Mathematical Analysis

### Energy Conservation

**Kinetic Energy**:
[latexmath]
++++
E_k = \frac{1}{2}mv^2
++++

**Energy Lost per Collision**:
[latexmath]
++++
\Delta E = E_{initial} - E_{final} = E_{initial} - (e^2 \cdot E_{initial})
\Delta E = E_{initial}(1 - e^2)
++++

With e = 0.8:
[latexmath]
++++
\Delta E = E_{initial}(1 - 0.64) = 0.36 \cdot E_{initial}
++++

36% of kinetic energy is lost per collision.

### Multi-Collision Energy Loss

For n collisions:
[latexmath]
++++
E_{final} = E_{initial} \times e^{2n}
++++

*After 1 collision*: 64% of energy remains
*After 2 collisions*: 41% of energy remains
*After 3 collisions*: 26% of energy remains
*After 5 collisions*: 11% of energy remains

The ball eventually comes to rest due to accumulated energy loss.

### Velocity Reflection Derivation

The reflection formula can be derived from vector algebra:

1. **Decompose Velocity**:
[latexmath]
++++
\vec{J} = \vec{J}_{\parallel} + \vec{J}_{\perp}
++++

2. **Project onto Normal**:
[latexmath]
++++
\vec{J}_{\perp} = (\vec{J} \cdot \vec{N})\vec{N}
++++

3. **Reflect Perpendicular Component**:
[latexmath]
++++
\vec{J}'_{\perp} = -\vec{J}_{\perp} = -(\vec{J} \cdot \vec{N})\vec{N}
++++

4. **Combine**:
[latexmath]
++++
\vec{R} = \vec{J}_{\parallel} + \vec{J}'_{\perp}
\vec{R} = (\vec{J} - (\vec{J} \cdot \vec{N})\vec{N}) - (\vec{J} \cdot \vec{N})\vec{N}
\vec{R} = \vec{J} - 2(\vec{J} \cdot \vec{N})\vec{N}
++++

### Physics Principles Illustrated

1. **Newton's Laws**:
* First law: Ball continues in motion until collision
* Second law: F = ma (gravity accelerates ball)
* Third law: Action-reaction pairs in collisions

2. **Conservation Laws**:
* Energy: Kinetic energy decreases over time (non-conservative collisions)
* Momentum: Momentum is conserved in collisions (with mass = 1 for simplicity)

3. **Geometric Principles**:
* Reflection angle equals incident angle
* Normal vectors are perpendicular to surfaces
* Tangent vectors are parallel to surfaces

== Troubleshooting

### Ball Gets Stuck in Peg

**Symptoms**: Ball becomes trapped inside peg or wall

**Causes**:
* Ball velocity too high (tunneling)
* Look-ahead collision detection missed collision
* Peg/ball size mismatch

**Solutions**:
[source, python,linenums]
----
# Reduce maximum velocity
if ball.velocity.length() > max_speed:
    ball.velocity = ball.velocity.normalize() * max_speed

# Ensure ball is pushed out of collision
if would_collide:
    ball.velocity = reflected * bounciness
    ball.x = ball.x - ball.velocity.x * 2  # Move back
    ball.y = ball.y - ball.velocity.y * 2
----

### Ball Loses Energy Too Fast

**Symptoms**: Ball stops moving very quickly

**Causes**:
* Bounciness too low
* Too many collisions per frame
* Incorrect gravity scaling

**Solutions**:
[source, python,linenums]
----
# Increase bounciness
ball.bounciness = 0.9  # Higher retention

# Reduce gravity
board.inclination = 1  # Minimize effective gravity
----

### Collision Response Incorrect

**Symptoms**: Ball bounces in wrong direction

**Causes**:
* Normal vector calculated incorrectly
* Reflection formula has sign error
* Normal direction (inward/outward) confusion

**Solutions**:
[source, python,linenums]
----
# Verify normal direction
# Normal should point AWAY from surface
normal = surface.get_normal(ball)

# Ensure normal is not zero
if normal.length() == 0:
    normal = Vector2(0, 0)  # Fallback

# Double-check reflection formula
reflected = velocity - 2 * velocity.dot(normal) * normal
----

== Code Implementation

### Key Methods

**BumperView.update()**:
[source, python,linenums]
----
def update(self):
    '''Update game state with physics simulation.'''
    # Apply forces
    self.ball.add_force(Vector2(0, GRAVITY * self.ball.mass))
    self.ball.add_force(Vector2(0, -GRAVITY * (1 - self.board.inclination) * self.ball.mass))

    # Predict collision
    new_x = self.ball.x + self.ball.velocity.x
    new_y = self.ball.y + self.ball.velocity.y
    would_collide, colliding_object = self.board.would_ball_collide(
        self.ball, new_x, new_y
    )

    # Handle collision or update
    if would_collide and colliding_object:
        normal = colliding_object.get_normal(self.ball)
        reflected = self.ball.velocity - 2 * self.ball.velocity.dot(normal) * normal
        self.ball.velocity = reflected * self.ball.bounciness
    else:
        self.board.update()
        self.ball.update()
----

**Board.would_ball_collide()**:
[source, python,linenums]
----
def would_ball_collide(self, ball, new_x, new_y):
    '''Check if ball would collide at new position.'''
    # Store current position
    old_x, old_y = ball.x, ball.y

    # Temporarily update position
    ball.x = new_x
    ball.y = new_y

    # Check for collision
    collided_object = pygame.sprite.spritecollideany(
        ball, self.obstacles + self.boundaries
    )

    # Restore original position
    ball.x, ball.y = old_x, old_y

    return (collided_object is not None), collided_object
----

== Performance Optimization

### Collision Detection Optimization

**Current**: Linear search through all obstacles
**Optimization**: Spatial partitioning (quadtree or grid)

[source, python,linenums]
----
# Grid-based spatial partitioning
class SpatialGrid:
    def __init__(self, width, height, cell_size):
        self.cell_size = cell_size
        self.cells = {}

    def add(self, object):
        cell_x = int(object.rect.x / self.cell_size)
        cell_y = int(object.rect.y / self.cell_size)
        cell = self.cells.setdefault((cell_x, cell_y), [])
        cell.append(object)

    def get_nearby(self, object):
        cell_x = int(object.rect.x / self.cell_size)
        cell_y = int(object.rect.y / self.cell_size)
        return self.cells.get((cell_x, cell_y), [])
----

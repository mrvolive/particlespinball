== Getting Started

=== Prerequisites

[role="prerequisites"]
* **icon:python[role=red] Python 3.13+** - Latest Python version required

=== Installation

.Installation Commands
[source, bash,linenums]
----
git clone <repository-url>
cd particlespinball
make install
make run
----

TIP: The `make install` command creates a virtual environment and installs all dependencies automatically.

=== First Steps

. **Run the application** - Execute `make run` to see available demos
. **Explore different views** - Navigate through the home screen to experience different physics simulations
. **Read the architecture documentation** - Understand the codebase structure and design patterns
. **Check the development guide** - Learn how to contribute and extend the project

== Project Structure

.Project Directory Tree

----

├── src/                    # Source code

== Key Concepts

=== Physics Simulation

The project implements realistic physics including:

[.physics-features]
* **icon:arrow-down[role=red] Gravity** - Constant downward force affecting all objects
* **icon:expand[role=blue] Collision Detection** - Precise collision between objects
* **icon:calculator[role=green] Force Application** - Vector-based force calculations
* **icon:rocket[role=orange] Velocity Integration** - Position updates based on velocity

=== Game Architecture

The project follows established patterns:

[.architecture-patterns]
* **icon:project-diagram[role=purple] Model-View-Controller** - Separation of game logic, rendering, and input
* **icon:th[role=teal] Sprite Pattern** - Efficient collision detection and rendering
* **icon:industry[role=maroon] Factory Pattern** - Dynamic creation of different game views

=== Educational Value

This project serves as an educational tool for:

[.educational-benefits]
* **icon:atom[role=navy] Physics Education** - Hands-on physics simulation
* **icon:code[role=olive] Game Development** - Complete game development pipeline
* **icon:sitemap[role=lime] Software Architecture** - Modular design principles
* **icon:python[role=fuchsia] Python Programming** - Practical Python application development

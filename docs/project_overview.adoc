The Particle Pinball project is a physics-based simulation game that demonstrates fundamental physics concepts through an interactive pinball game. Built with Python and Pygame, this project serves as both an educational tool and an entertaining application.

[.project-highlights]
* **icon:graduation-cap[role=blue] Educational** - Learn physics through interactive simulation
* **icon:gamepad[role=green] Entertaining** - Engaging gameplay with realistic physics
* **icon:code[role=orange] Open Source** - Free to use, modify, and contribute
* **icon:users[role=purple] Community Driven** - Built by and for the physics education community

== Project Structure

The project follows a modular architecture with clear separation of concerns:

.Project Architecture Diagram
[source, text,subs="attributes+"]
----
src/
├── core/           # Core physics and world management
│   └── world.py   # Physics constants and world configuration
├── objects/        # Game objects and entities
│   ├── ball.py     # Ball physics and movement
│   ├── board.py    # Game board and collision management
│   ├── bumper.py  # Dynamic circular obstacles
│   ├── peg.py      # Static circular obstacles
│   ├── horizontal_wall.py  # Horizontal wall obstacles
│   └── vertical_wall.py    # Vertical wall obstacles
├── utils/          # Utility functions and helpers
│   └── __init__.py # Module initialization
├── views/          # User interface and rendering
│   ├── view.py     # Base view class
│   ├── home_view.py     # Main menu screen
│   ├── game_view.py     # Main pinball game
│   └── demos/          # Physics demonstrations
│       ├── falling_ball_view.py     # Gravity demonstration
│       ├── ball_bounce_view.py      # Collision demonstration
│       └── spring_bounce_view.py    # Spring physics demonstration
└── main.py         # Application entry point
----

[.module-responsibilities]
[cols="1,3",options="header"]
|===
| Module | Responsibilities
| **core/**
| * Define global physics constants
* Manage coordinate system transformations
* Provide centralized configuration
* Handle timing and frame rate management

| **objects/**
| * Implement game entities and behaviors
* Handle physics calculations per object
* Manage collision detection and response
* Maintain object state and lifecycle

| **utils/**
| * Provide common mathematical operations
* Handle coordinate transformations
* Offer shared helper functions
* Support cross-module utilities

| **views/**
| * Render game objects to screen
* Handle user input and events
* Manage navigation between screens
* Provide user interface elements
|===

== Getting Started

.Getting Started Checklist
. **Clone the Repository**
+
[source, bash,linenums]
----
git clone <repository-url>
cd particlespinball
----

. **Install Dependencies**
+
[source, bash,linenums]
----
make install
----
+
*This command creates a virtual environment and installs all required Python packages.*

. **Run the Application**
+
[source, bash,linenums]
----
make run
----
+
*Launch the Particle Pinball application and explore the different physics demonstrations.*

. **Explore the Demos**
+
* Use the home screen to navigate between different physics simulations
* Experiment with different parameters and settings
* Observe how physics concepts are applied in real-time

TIP: The first time you run `make install`, it may take a few minutes to download and install all dependencies.
